# SafeZone

**SafeZone: AI-Assisted Intelligent Police Patrol Deployment and Emergency Response System** is a final-year engineering project for explainable crime-risk analysis, strategic patrol positioning, and real-time emergency response.

The repository is currently at **Stage 3: Authentication and RBAC**. It contains runnable application shells, the normalized PostgreSQL/PostGIS persistence model, citizen registration, email/password login, JWT access tokens, active-account validation, and reusable role authorization dependencies. Crime CRUD, maps, risk calculation, PRP optimization, patrol allocation, SOS dispatch, live tracking, and notifications are intentionally not implemented yet.

## Technology stack

- Mobile: Flutter and Dart, with one role-based Citizen and Police application
- Admin dashboard: React and Vite
- Backend: Python and FastAPI
- Database: PostgreSQL with PostGIS
- ORM and migrations: SQLAlchemy 2.x and Alembic
- Validation: Pydantic
- Future optimization/analytics: NumPy, Pandas, and Google OR-Tools
- Future routing: provider-independent OSRM-compatible abstraction
- Future notifications: Firebase Cloud Messaging abstraction

## Local setup

### Prerequisites

- Python 3.11 or newer
- Node.js 20.19 or newer with npm
- Flutter stable with a Dart SDK compatible with `>=3.4.0 <4.0.0`

PostgreSQL/PostGIS is not required to run the health endpoint or metadata-only unit tests. Applying migrations requires a PostgreSQL database with PostGIS available. Its connection URL is represented safely in `.env.example`.

### Environment

Copy `.env.example` to `.env` and replace development placeholders locally. Never commit `.env` or real credentials. Frontend origins must be a JSON array of explicit origins; wildcard CORS is not supported.

### Backend

From the repository root:

```powershell
cd backend
py -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

Open `http://127.0.0.1:8000/health`. The expected response is:

```json
{"status":"ok","service":"SafeZone API","message":"API is running"}
```

Run backend tests with `python -m pytest` from `backend/`.

Apply the database migration from `backend/` after configuring `DATABASE_URL`:

```powershell
python -m alembic upgrade head
```

See `docs/DATABASE.md` for the domain model, PostGIS conventions, and migration requirements.

Authentication endpoints are documented in `docs/AUTHENTICATION.md`, crime management in `docs/CRIME_DATA.md`, spatial/routing conventions in `docs/GEOSPATIAL_SERVICES.md`, the explainable scoring formula in `docs/RISK_MODEL.md`, and candidate assumptions in `docs/CANDIDATE_GENERATION.md`. The interactive API documentation is available at `http://127.0.0.1:8000/docs` while the backend is running.

### Admin dashboard

```powershell
cd admin-dashboard
npm install
npm run dev
```

Run a production build check with `npm run build`.

### Flutter application

```powershell
cd mobile\safezone_app
flutter pub get
flutter analyze
flutter test
flutter run
```

Platform runner directories can be generated by an installed Flutter SDK when a target platform is selected; the repository currently keeps only the platform-neutral Stage 1 shell.
